## How do we know it works?

Success for the Procedure layer is defined by **"Any Agent Can Pick Up Any Procedure."** If an AI agent (or a human new to the project) can read a procedure and produce correct, high-quality output on the first try without additional instruction, the procedure has succeeded. Success is the "Self-Sufficiency of Instructions." If a procedure requires "context mining" or "human clarification" to be executed, it has failed its success criteria.

Another success criterion is **"Structural Compliance Consistency."** Every artifact produced by a procedure should be self-evidently correct in its form. For example, if the procedure defines a naming convention, then 100% of the files should follow that convention. If the procedure defines a template, then every section of the template should be correctly populated. Success is a system where the "Physical Form" of the work is perfectly aligned with the "Procedural Specification."

Finally, success is measured by **"Validation Speed."** A well-defined procedure should make the subsequent validation step trivial. If a human reviewer can audit an agent's work in a matter of seconds because the procedural compliance is obvious, the procedure has achieved its goal of reducing cognitive load. Success is when the "Atomic Level of Work" is so clear that it ceases to be a point of friction in the system.
