## How do we know it works?

Success for the Principles layer is measured by "Operational Friction Reduction." When principles are clearly defined and consistently followed, the system should operate smoothly, with minimal rework and fewer "architectural surprises." A primary success criterion is that principles are followed "without being invoked"—they become habit for both humans and agents. If a project can be completed without a single principle violation being flagged during review, the principles have succeeded.

Another success criterion is "Adherence Transparency." Every task output should be self-evidently compliant with the core principles. For example, if the principle is "1 Task = 1 File," then the file tree should clearly reflect this mapping. If the principle is "Markdown as Wire Protocol," all documentation should be in standard Markdown. Success is a system that "looks and feels" like DEX because its principles are visible in its every artifact.

Finally, success is defined by "Agent Autonomy within Guardrails." When an AI agent can successfully complete a complex task without needing human intervention to correct its approach, it proves that the principles are providing effective guidance. If an agent's work consistently passes human review on the first attempt because it adhered to the L0 principles, the layer has achieved its primary goal of enabling safe, aligned autonomy.
