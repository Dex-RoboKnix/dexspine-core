## What tools enable fundamental principles?

The tools for the Principles layer are focused on **"Structural Governance."** We use **Markdown Linters** and custom validation scripts (bash/python) to enforce the "Markdown as Wire Protocol" and naming convention principles. These tools provide immediate feedback to contributors, ensuring that work is correctly formatted before it even reaches the human review stage. We treat our Markdown as code, subjecting it to the same level of linting and structural scrutiny.

To support "Composability" and the "1 Task = 1 File" principle, we use **Template Generators**. These tools allow us to quickly spin up new filter applications or project tracks with the correct directory structure and cross-references already in place. By automating the creation of the "Geometry," we ensure that every new part of the system is a perfect fit for the existing foundation.

Finally, we rely on **Git Hooks** to enforce the "Human Veto" and review principles. Hooks can be configured to block commits that violate naming rules or to require a specific keyword in a commit message that indicates a human has audited the work. These tools are the "Digital Enforcers" of our principles, providing a first line of defense against entropy and unprincipled contributions.
