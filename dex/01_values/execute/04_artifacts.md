## What gets produced?

The primary artifacts produced by the Values layer are the **19 Filter Files** and the **DEXFILTER_APPLICATION.md** for this layer. These documents constitute the "System DNA" and are the source of truth for all downstream work. Each file is a tangible record of a specific analytical point (e.g., `01_definition.md`, `mve/va.md`), providing the necessary context for humans and agents to remain aligned.

Beyond the layer-specific files, this layer produces the root documents that govern the entire spine: `README.md`, `DEXFILTER.md`, and `REDUCTION_BY_ADDITION.md`. These are the "meta-artifacts" that define how the values are applied and how the system as a whole functions. They are the most critical artifacts in the DEX repository, serving as the entry point for all new contributors and the primary reference for all agents.

Finally, the Values layer produces **Audit Logs** (via Git history and CASESTUDY.md) that track how the system's beliefs have shifted or been reinforced over time. These logs are essential for maintaining the "Grounding Chain" and ensuring accountability. The artifacts of this layer are not code; they are "Cognitive Assets"—structured information that provides the meaning and purpose for any code that is subsequently written in the L1 and L2 layers.
