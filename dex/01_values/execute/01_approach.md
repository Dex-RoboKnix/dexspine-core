## How do we implement core values?

The implementation of Core Values follows a "Document, Reference, Audit" approach. First, the values are explicitly documented in the L0 foundation (this layer) using the universal `dexfilter` pattern. This ensures they are human-readable and machine-parseable from the start. We treat these documents not as passive text, but as the "system's constitution"—the highest level of authority that all subsequent layers must respect.

The second part of the approach is "Active Referencing." During the execution of any task, whether by a human or an agent, the relevant values must be explicitly linked and referenced. This is done through templates, checklist items, and decision logs. By making the values part of the daily workflow, we ensure they remain active in the system's "working memory" and are not forgotten during long-duration projects.

Finally, we implement values through "Regular Auditing." This is a quarterly process where the system's decisions, artifacts, and alignment are reviewed against the core beliefs. We use the 8:3:8 law to resolve any value conflicts that emerge and to refine our expression of the values as the system evolves. This "continuous grounding" ensures that the implementation stays true to the foundation even as the system's scale and complexity increase.
