## What limits core values?

The primary constraint on the Core Values is that they must be **Vendor-Agnostic**. To fulfill the system's purpose as a universal spine, the values cannot favor any specific commercial platform, model provider, or programming language. This constraint ensures that the DEX foundation remains portable and resilient to shifts in the technological landscape. Any value that relies on a specific tool or vendor is a violation of this constraint.

Another significant constraint is **Human-Readability**. The values must be expressed in plain text (Markdown) and structured in a way that a human can quickly understand and audit. This limits the complexity of the value statements. We prioritize clarity and directness over legalistic or academic precision. If a value cannot be explained to a human in 2-4 paragraphs, it is likely too complex to serve as an L0 foundation.

Finally, the values are constrained by the **Asymptotic Pursuit of Perfection**. We acknowledge that our expression of these values is inherently incomplete (the 99.99% state). This constraint prevents the values from becoming dogmatic or rigid. Instead, it encourages a "continuous improvement" mindset, where the values are refined as new insights emerge from the Human (hu.md) and LLM (llm.md) perspectives. The values are the "best possible" foundation for the current state of the system.
