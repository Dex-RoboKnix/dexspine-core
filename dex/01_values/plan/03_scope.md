## What is included and excluded?

The scope of the Values layer encompasses the universal, foundational beliefs that apply to all DEX-compliant systems. This includes core philosophies such as the "Infrastructure, Not Product" mandate, the preservation of human authority (Layer 8 Veto), the "Markdown as Wire Protocol" principle, and the commitment to vendor-agnostic knowledge sharing. These values are intended to be broad enough to guide any cognitive system while being specific enough to be enforceable.

Included in this scope is the definition of the "Grounding Chain"—the requirement that all downstream artifacts (processes, procedures, patterns) must be traceable back to these core values. The scope also covers the ethical considerations of human-LLM collaboration, specifically the "Asymptotic 100%" pursuit of perfection and the "8:3:8 Law" for resolving ambiguity.

Explicitly excluded from the Values layer are implementation details, project-specific rules, or transient tool configurations. While values *inform* these details, they do not *contain* them. For example, "Markdown as Wire Protocol" is a value, but the specific linter configuration for a markdown file is a procedure (Layer 05). The Values layer is concerned with the "Why" and the "What We Believe," leaving the "How" and "When" to the layers above.
