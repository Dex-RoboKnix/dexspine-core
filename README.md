## Overview

DexSpine is the deterministic cognitive infrastructure layer of DexRoboKnix. It defines the 8:3:8 dexfilter, the six-layer chain (Values → Principles → Policy → Process → Procedure → Pattern), the `dex(scope, @context)["subject"]` syntax, and the Reduction by Addition principle. DexSpine is the methodology and message format used by DexCLI and ADE.

## OpenCore

This is the Core (open source) edition. An Enterprise edition with additional connectors, managed hosting, and commercial support is maintained separately under the same organisation.
